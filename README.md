# Macro_detection

This code is developed to calculate the astrophysical constraints (white dwarfs and neutron stars) and gravitational wave signals for macroscopic dark matter, mainly sub-saturated Fermi balls. Detailed discussions can be found in arXiv [2511.23263](https://arxiv.org/abs/2511.23263).

## Authors

Siyu Jiang, Aidi Yang, Fa Peng Huang

## MWDD-export.csv

Data that is downloaded from [Montreal White Dwarf
Database](https://www.montrealwhitedwarfdatabase.org).

## detectabilityv2-online.py

White dwarf and Neutron star constraints on Fermi-ball DM.

## SNRfermi-online.py

The sensitivity curve of TianQin, LISA and Taiji on Fermi-ball DM.

## Fisher-online.py

Fisher analysis for a signal at TianQin, LISA and Taiji induced by Fermi-ball DM.
